# Flat Isometric references

The owner's references for the **Flat Isometric** drawing style (26 November 2026). The rules derived from them live in `index.html` (`ISO_HOUSE_STYLE`, `ISO_DRAWING_RULES`, `ISO_PALETTE_RULES`) and in [the guide](../../docs/visual-communication-research.md#flat-isometric-style). Every Isometric generation also sends Claude two small copies from `prompt/` (1000 × 563 WebP, about 750 tokens each): the layout that best fits the brief, plus a second one for drawing style. The page fetches them by relative URL, so publish `prompt/` beside the page and keep it next to `index.html`. The full-size files here are not sent.

## Palette

- `palette.png`: the neutral base (White, Paper gray, Light gray, Mid gray, Dark gray, Graphite) and eight muted accents (Coral, Terracotta, Ochre, Sage, Muted teal, Muted blue, Lavender, Dusty rose). One accent per infographic; the colour marks the object or process the infographic is about.

## Principles for the whole series (owner)

- Monochrome grey base.
- One muted colour that carries meaning.
- Simple geometric and organic forms.
- Minimal depth and soft silhouettes.
- Contrasting labels and unambiguous leaders.
- Large, clearly readable illustrations.
- Isometry where it helps explain the information.
