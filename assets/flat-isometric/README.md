# Flat Isometric asset library — V2

47 self-contained SVG illustrations for Info-to-Graphics. Each SVG is a transparent, resolution-independent drawing, with an English title, intrinsic viewBox, and separate accent paths where applicable. The revised illustrations use original reference-style drawings converted to editable vector contours, with a unified neutral palette and semantic accent colors. There are no embedded raster images or linked fonts.

## Using the assets

- Select assets in manifest.json by category, tags, file, viewBox, and accent layer.
- Preserve each asset’s aspect ratio and keep labels and connectors outside the illustration.
- Recolor fill attributes on paths marked data-recolor-fill="true" within the corresponding data-accent group. The data-tone attribute identifies base, shade and light variants. Use the neutral palette for incidental objects.
- Namespace SVG IDs when combining multiple assets in one document.
- Vector paths are organized by fill tone; compound paths may contain multiple regions of the same tone. Action-specific objects are included in the people illustrations.
